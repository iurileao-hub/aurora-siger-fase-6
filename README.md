## Objetivo

Protótipo em Python que organiza dados operacionais e de comunicação da colônia
Aurora Siger, avalia a confiabilidade de previsões de latência, prioriza alertas
críticos com **heap**, permite busca por prefixo com **trie** e gera uma análise
de apoio à decisão.
